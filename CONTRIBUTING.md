# Contributing to agent-replay

Thanks for your interest in improving agent-replay. Bug reports, missed detections, false positives, importers for
other agent frameworks, new rules and documentation fixes are all welcome.

## Getting set up

```bash
git clone https://github.com/OsamaWehbi/agent-replay.git
cd agent-replay
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
pre-commit install
```

## Before you open a pull request

```bash
ruff check .
ruff format --check .
pytest
python examples/replay_demo.py
```

CI runs the same checks on Python 3.11, 3.12 and 3.13 on Linux and on Windows, plus Bandit, pip-audit and Gitleaks.

## Adding or changing a rule

Rules live in `src/agent_replay/rules.py`. Each new rule or pattern needs:

- a test with a small trace that triggers it, built with `make()` from `tests/conftest.py`;
- a test showing that a normal run of the same kind does not trigger it;
- an entry in the rules table in the README.

The example traces in `examples/traces` are generated by `python scripts/make_examples.py`. The clean ones must stay
at zero findings.

## Guidelines

- Open an issue first for larger changes so we can agree on the approach.
- Keep pull requests focused. One topic per PR is easier to review.
- Use conventional commit messages such as `feat`, `fix`, `docs`, `test` and `chore`.
- Never commit real traces. They contain whatever the agent saw. Build test traces by hand, and use documented
  example credentials such as `AKIAIOSFODNN7EXAMPLE`.
